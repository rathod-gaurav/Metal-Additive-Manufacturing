# Study-guide scripts

One script per part of "CALPHAD Study Guide: From Gibbs Energy to the KKS Server".
Run them from anywhere, e.g. from the calphad_server folder:

    python learning/part5_pycalphad.py

part7_http.py and part9_tasks.py need the server running first:

    python calphad_server.py --tdb cuni_cost507.tdb --tdb alni_dupin_2001.tdb
